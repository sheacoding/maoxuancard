# 毛选卡片

Linkbit V2（ESP32-C3 + GDEY0213Z98 三色墨水屏）的离线书摘应用。屏幕横向显示一条完整语录；A/C 循环翻页，B 随机，B 长按三秒显示手机管理入口。设备闲置五分钟后保留画面并深度休眠，B 唤醒不会随机换页；联网取得北京时间后，每天 08:00 自动切换下一条。

## 手机管理

首次启动时连接屏幕所示设备热点，再访问 `http://192.168.4.1/`；配网后也可从同一 Wi-Fi 访问屏幕所示地址。管理页沿用六位密码和 Digest 认证，可管理精选库、个人书摘、收藏、配图、导入导出及卡面预览。

- “预览”只取得固件真实排版生成的黑/红位图，不刷新墨水屏。
- “上屏”才提交刷新，页面依次报告等待、刷新中、完成或失败。
- 内置 30 条只读；编辑会复制成个人书摘。个人书摘最多 100 条。
- JSON 导出不包含 Wi-Fi 或管理密码；导入先完整校验，再逐条追加并去重。
- 设置页显示设备北京时间和下次自动换句时间；时钟无效时每六小时联网重试。配网失败会保留密码输入，候选连接结束时清除驱动临时凭据，避免污染下一次尝试。

## 构建与烧录

构建入口使用 PowerShell。请先安装 Bun、FFmpeg、GCC/G++（支持 C++17）和 PlatformIO Core，并确保 `bun`、`ffmpeg`、`gcc`、`g++`、`platformio` 位于 PATH。如需指定 PlatformIO 可执行文件，可设置 `$env:PLATFORMIO`。固件依赖与工具链版本固定在 `platformio.ini`；首次运行会下载到项目内的 `.pio/` 与 `.pio-core/`，需要网络访问。

```powershell
git clone https://github.com/sheacoding/maoxuancard.git
cd maoxuancard
```

```powershell
.\build.ps1 -Action test
.\build.ps1 -Action build
.\build.ps1 -Action upload -Port COM5
.\build.ps1 -Action monitor -Port COM5
```

烧录命令使用 PlatformIO 标准镜像流程，不执行整片擦除，也不上传 LittleFS 镜像。分区布局与既有 Linkbit 固件逐项一致；个人数据位于 LittleFS 的 `/maoxuancard`，设置位于独立 NVS 命名空间 `maoxuancard`，文件保存采用临时文件提交。

## 内容与素材

30 条正文、篇名、卷次和逐条正文链接位于 `content/quotes.json`。核对方法、官方卷目录、官方全文页及肖像授权页记录在 `content/sources.json`。六幅主题简笔画由 `tools/prepare.ts` 原生生成；两款肖像由有来源记录的原图离线转换。

## 验证

`tools/native.ts` 编译并执行固件真实核心、时钟策略、中文字库和排版；`tests/check.ts` 检查浏览器数据边界并解码全部 30 张卡面。主机检查覆盖每日边界、循环翻阅、随机去重、连续操作合并、按键短按/长按/唤醒、导入去重、失败与中断保存、UTF-8、JSON 和网络截止时间。实物屏幕、按键、定时唤醒与断电恢复仍以设备验收为准。

每日计划固定使用北京时间：07:58 预唤醒并尝试 SNTP 校时，08:00 按当前“全部／收藏”集合顺序前进。同一天最多自动切换一次；错过 08:00 后当天首次取得有效时间时补切一次，不按遗漏天数连续补切。RTC 时间可跨深睡保存，但完全断电后需要重新联网取得时间。

主要接口：`GET /api/cards`、`POST /api/preview`、`POST /api/display`、`GET /api/status`、`POST /api/collection`、个人书摘 CRUD、收藏/配图更新及 Wi-Fi 扫描配置。全部写接口要求 Digest 认证并校验同源请求。
